# بطارية Redragon M913 في شريط النظام

أداة Windows مستقلة تقرأ بطارية فأرة Redragon M913 المتوافقة مباشرة عبر HID وتعرض النسبة بجوار الساعة.

[English](README.md)

## التنزيل

نزّل الحزمة المختبرة الحالية من [إصدارات GitHub](https://github.com/Doomguy-BFG9000/redragon-m913-battery-tray/releases)، ثم فك ضغط الملف وشغّل `Install.cmd`.

## المزايا

- رقم بطارية كبير وعالي التباين داخل شريط النظام.
- لوحة تحكم نظيفة تضم مقياس بطارية كبيرًا، وحالة البطارية، ووقت آخر تحديث، وزر تحديث يدوي، والتحكم بالتشغيل مع Windows، وزرًا مباشرًا لبرنامج Redragon.
- إطار أخضر من 50–100%، وكهرماني من 21–49%، وتحذير أحمر نابض عند 0–20%.
- خمس عينات مع وسيط وتأكيد التغيير مرتين لتقليل تذبذب القراءة.
- تحديث تلقائي كل دقيقة وتشغيل تلقائي مع Windows عبر مفتاح Run واختصار داخل مجلد Startup للمستخدم الحالي.
- تشغيل مستقل واستعادة تلقائية بعد الإغلاق غير المتوقع أو فقدان تسجيل الأيقونة.
- واجهة عربية على Windows العربي، وإنجليزية على اللغات الأخرى، مع اختيار لغة يدوي محفوظ.
- لا اتصال بالإنترنت، ولا إعلانات أو تحليلات، ولا حاجة لبقاء برنامج Redragon مفتوحًا.

## المتطلبات

- Windows 11 بنظام 64 بت، أو إصدار Windows 10 Enterprise/LTSC مدعوم حاليًا بنظام 64 بت (الإصدار 1809 أو أحدث).
- فأرة/مستقبل M913 متوافق. راجع `SUPPORTED-DEVICES.md`.
- إصدار `win-x64` مستقل ولا يحتاج إلى تثبيت ‎.NET بصورة منفصلة.

## التثبيت

1. فك ضغط ملف ZIP كاملًا.
2. شغّل `Install.cmd` بالنقر المزدوج.
3. ستظهر أيقونة البطارية في منطقة الإشعارات. قد يضع Windows الأيقونات الجديدة داخل قائمة الأيقونات المخفية أول مرة؛ يمكن تثبيتها ظاهرة من إعدادات شريط المهام.
4. عند التشغيل الأول، اتبع رسالة الإعداد العربية وفعّل **Redragon M913 Battery Tray** ضمن **أيقونات علبة النظام الأخرى**. لا يستطيع تثبيت الأيقونة في هذا الموضع إلا Windows والمستخدم المسجّل دخوله.

التثبيت خاص بالمستخدم الحالي ولا يحتاج صلاحيات مسؤول. يُثبت البرنامج داخل `%LOCALAPPDATA%\Programs\RedragonM913BatteryTray`، ويفعّل مسارين مستقلين للتشغيل مع Windows، ويضيف خيار إزالة إلى تطبيق الإعدادات.

## الاستخدام

- نقرة واحدة: عرض النسبة الحالية في إشعار.
- نقرة مزدوجة: فتح لوحة التحكم.
- زر الفأرة الأيمن: فتح لوحة التحكم، أو إبقاء نسبة البطارية ظاهرة، أو التحديث، أو تغيير التشغيل التلقائي، أو التبديل بين العربية والإنجليزية، أو فتح Redragon، أو الخروج.

لا يلزم إبقاء برنامج Redragon الأصلي مفتوحًا. عند دخول الفأرة في وضع السكون قد تصبح القراءة غير متاحة مؤقتًا، ثم تعود بعد إيقاظ الفأرة.

تراقب عملية صغيرة ثانية البرنامج وتعيد تشغيله بعد الإغلاق غير المتوقع بنحو ثانيتين. يستعيد البرنامج المراقب أو تسجيل الأيقونة المفقود في فحص كل عشر ثوانٍ. اختر **خروج** من قائمة الأيقونة لإيقاف العمليتين عمدًا. تتوقف الاستعادة بعد خمس محاولات خلال عشر دقائق لمنع حلقة أعطال. إذا أُغلقت العمليتان معًا، شغّل البرنامج يدويًا، أو سيعمل عند تسجيل الدخول التالي إلى Windows.

## الإزالة

من **الإعدادات > التطبيقات > التطبيقات المثبتة > Redragon M913 Battery Tray**، أو بتشغيل `Uninstall.cmd` من الحزمة بعد فكها. تحذف الإزالة ملفات البرنامج وملفات التشخيص المحلية افتراضيًا.

## الخصوصية والتوقيع

يحفظ البرنامج الحالة والأخطاء وسجل التشغيل المحدود وملفات الاستعادة محليًا فقط داخل `%LOCALAPPDATA%\RedragonBatteryTray` ولا يجري اتصالات شبكية. الإصدار 1.6.0 إصدار مفتوح المصدر وغير موقّع رقميًا، لذلك قد يعرض Windows تحذير ناشر غير معروف أو SmartScreen. تحقّق من بصمة SHA-256 المنشورة إذا ظهر تحذير.

هذه أداة غير رسمية ومستقلة وليست تابعة لشركة Redragon أو معتمدة منها. راجع `NOTICE.md`.
